# RuHub - Русский GitHub + Утилиты

Расширение для браузера, которое русифицирует основные элементы интерфейса GitHub и добавляет полезные кнопки для разработчиков.

## 🚀 Особенности
- 🇷🇺 **Русский интерфейс:** Перевод навигации (Pull requests, Issues, Settings и др.).
- 💻 **Web VS Code:** Быстрая кнопка перехода в `github.dev` прямо из шапки репозитория.
- 📦 **Скачать ZIP:** Кнопка для мгновенного скачивания архива репозитория.
- ⚡ **Быстродействие:** Интеграция с SPA-архитектурой GitHub — страницы переводятся на лету без перезагрузок.
- 🎨 **Дизайн:** Полная поддержка светлой и темной тем оформления.

## 🛠 Установка (Chrome / Edge / Яндекс Браузер)

1. Перейдите на страницу **[Releases](../../releases/latest)** и скачайте архив `github-ru-v1.0.zip`.
2. Распакуйте архив в любую удобную папку (например, `github-ru-extension`).
3. Откройте браузер и перейдите на страницу расширений: 
   - Chrome / Яндекс: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
6. Выберите папку, в которую вы распаковали архив.
7. Готово! Зайдите на любой репозиторий GitHub, чтобы увидеть изменения.

## ⚙️ Настройка своего перевода
Вы можете легко добавить собственные слова для перевода:
1. Откройте файл `content.js` в любом текстовом редакторе.
2. В объекте `DICTIONARY` добавьте новую пару в формате `"Оригинал": "Перевод"`.
3. Сохраните файл.
4. Обновите страницу расширений (`chrome://extensions/`) нажав на кнопку "Обновить" (иконка круглой стрелки) на карточке расширения.
5. Перезагрузите страницу GitHub в браузере.
