Легковесное браузерное расширение для Google Chrome, Microsoft Edge, Яндекс Браузера, Brave и Opera, которое качественно переводит интерфейс GitHub на русский язык и добавляет удобные инструменты разработчика в шапку любого репозитория.

Собрано по стандарту **Manifest V3** без сборщиков, внешних библиотек и тяжелых зависимостей — чистый нативный JavaScript, работающий со скоростью браузера.

---

## ✨ Ключевые возможности

### 🇷🇺 Качественный контекстный перевод
- Переводит ключевые элементы навигации репозитория (Code, Issues, Pull requests, Actions, Projects, Wiki, Security, Insights, Settings).
- Переводит кнопки действий (Star, Fork, Watch, Sponsor, Pin, Unwatch).
- Локализует разделы коммитов, веток, релизов, тегов, метаинформацию и системные бейджи.
- Поддерживает перевод атрибутов `aria-label`, `placeholder`, `title` и `data-content` для корректной работы скринридеров и всплывающих подсказок.

### 🛡️ 100% защита исходного кода от перевода
- Строго изолирует пользовательский контент: функция фильтрации узлов `shouldSkipNode` исключает теги `<pre>`, `<code>`, `<textarea>`, diff-таблицы, вьюеры исходных файлов (`.blob-wrapper`, `.blob-code`), подсветку синтаксиса и редакторы (Monaco, CodeMirror, Lexical).
- Ваши коммиты, исходный код, файлы конфигурации и Markdown-документы в репозиториях остаются в первозданном виде.

### ⚡ Поддержка Turbo / PJAX переходов
- GitHub работает как Single Page Application без полных перезагрузок страниц. RuHub использует оптимизированный `MutationObserver` с дебаунсом 80 мс — перевод и кнопки мгновенно применяются при переходе по ссылкам и подгрузке контента без мерцания и утечек памяти.

### 🚀 Быстрые действия разработчика (Quick Actions)
В шапку любого репозитория рядом со стандартными кнопками добавляются два удобных инструмента:
- **`VS Code`** — моментально открывает текущий репозиторий в веб-версии редактора Visual Studio Code (`github.dev`) с сохранением текущего пути и ветки.
- **`ZIP`** — прямая ссылка на скачивание архива последней версии ветки (`/archive/HEAD.zip`) в один клик без необходимости открывать выпадающее меню «Code».

### 🎨 Нативная интеграция стилей
- Кнопки расширения оформлены в полном соответствии с дизайн-системой GitHub Primer: идеально вписываются в интерфейс как в тёмной (Dark Mode), так и в светлой (Light Mode) теме оформления.

### 🔒 Приватность и безопасность
- Никакой телеметрии, аналитики и обращений к сторонним серверам. Весь код работает исключительно в локальной песочнице вашего браузера.

## 📦 Установка

Поскольку расширение разработано для индивидуального использования и максимальной прозрачности кода, оно устанавливается напрямую из исходников:

1. **Скачайте репозиторий:**
   - Нажмите зелёную кнопку **`Code`** → **`Download ZIP`** (или [скачайте по прямой ссылке](https://github.com/domovoyproj/github-ru/archive/refs/heads/main.zip)).
   - Распакуйте скачанный архив в удобную папку на компьютере.

2. **Откройте менеджер расширений браузера:**
   - Chrome / Brave: `chrome://extensions/`
   - Яндекс Браузер: `browser://extensions/`
   - Microsoft Edge: `edge://extensions/`

3. **Включите «Режим разработчика»** (тумблер *Developer mode* в правом верхнем углу).

4. **Нажмите «Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с распакованным репозиторием (где находится файл `manifest.json`).

5. Готово! Откройте любую страницу на [GitHub](https://github.com) — интерфейс автоматически переведётся на русский язык.

## 🛠 Настройка и расширение словаря

Словарь терминов вынесен в открытый объект `DICTIONARY` в начале файла `content.js`. Вы можете легко добавить собственные фразы или скорректировать существующие:

```javascript
const DICTIONARY = {
  // Навигация
  "pull requests": "Пул-реквесты",
  "issues": "Задачи",
  
  // Добавьте свои варианты:
  "discussions": "Обсуждения",
  "security": "Безопасность"
};
```

- Поиск осуществляется без учёта регистра символов и лишних пробелов по краям.
- После изменения словаря откройте страницу расширений в браузере и нажмите значок **Обновить** (🔄) на карточке RuHub.
