Легковесное и быстрое расширение для браузеров (Chrome, Edge, Яндекс Браузер, Brave, Opera), которое аккуратно русифицирует ключевые элементы интерфейса GitHub и добавляет удобные кнопки быстрого доступа прямо в шапку репозитория.

---

## ✨ Основные возможности

- 🇷🇺 **Бережная русификация:** Перевод навигации репозитория (*Пул-реквесты*, *Задачи*, *Код*, *Действия*, *Релизы*, *Аналитика*, *Настройки*), меню профиля и кнопок действий.
- 🛡️ **Защита исходного кода:** Расширение автоматически исключает из перевода блоки кода (`<pre>`, `<code>`, `.highlight`, `.blob-code`), diff-просмотр, редакторы (Monaco / CodeMirror) и поля ввода. Исходный код проектов остаётся нетронутым!
- 💻 **Кнопка Web VS Code:** Мгновенный переход к редактированию любого репозитория в браузере через `github.dev` в один клик.
- 📦 **Кнопка «Скачать ZIP»:** Быстрое скачивание архива текущей ветки без необходимости открывать выпадающее меню `<> Code`.
- ⚡ **Нулевая задержка (SPA-совместимость):** Построено на нативном `TreeWalker` и `MutationObserver` с дебаунсингом — работает плавно при переходах между страницами без перезагрузки.
- 🎨 **Нативная тема:** Полная интеграция со светлой и тёмной темами GitHub.

## 🛠️ Установка в браузер (Chrome / Edge / Яндекс / Brave)

1. Скачайте проект или релизный архив репозитория (`Code -> Download ZIP` или клонируйте репозиторий).
2. Распакуйте архив в любую удобную папку на компьютере.
3. Откройте страницу управления расширениями в вашем браузере:
   - **Google Chrome / Brave:** `chrome://extensions/`
   - **Яндекс Браузер:** `browser://extensions/`
   - **Microsoft Edge:** `edge://extensions/`
4. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
6. Выберите папку с файлами расширения (`manifest.json`, `content.js`, `styles.css`).
7. Готово! Перейдите на любую страницу [GitHub](https://github.com) — интерфейс автоматически станет на русском языке.

## ⚙️ Добавление своих слов в словарь

Если вы хотите расширить словарь перевода:
1. Откройте `content.js` в любом текстовом редакторе.
2. В объекте `DICTIONARY` добавьте нужную пару:
   ```javascript
   "original text": "Перевод на русский",
   ```
3. Сохраните файл и нажмите кнопку **Обновить** (🔄) на карточке расширения в браузере.
