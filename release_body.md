### Added
- **Русский интерфейс:** Перевод основных элементов навигации GitHub (Pull requests, Issues, Settings и др.).
- **Кнопка Web VS Code:** Позволяет в один клик открыть любой репозиторий в веб-редакторе `github.dev`.
- **Кнопка Скачать ZIP:** Мгновенное скачивание архива текущего репозитория.

### Improved
- **Быстродействие:** Интеграция с GitHub Turbo (SPA) через `MutationObserver` — страницы переводятся на лету без видимых задержек.
- **Дизайн:** Интегрированные кнопки автоматически подстраиваются под текущую тему GitHub (светлую или темную).
